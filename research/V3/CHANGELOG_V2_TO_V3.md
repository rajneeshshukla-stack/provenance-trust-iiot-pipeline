## 7. Corrections after the independent pre-submission audit (4 November 2026)

An independent review agent audited the first build of the V3 package against the V3 prompt (numbers recomputed from the
raw files, wording, integrity, issue matrix, consistency, archive). It found no fabricated result or reference; the
following findings were verified against code and data and corrected before the final build:

* B5 definition: B5's automated reviewer acts on every releasable quarantine reason (`review.RELEASABLE`), not only on
  feed holds, so B5 differs from PBTI in the conflict response *and* the reviewer; PBTI-R isolates the conflict
  response. Corrected in Methods, Discussion and `docs/BASELINES.md` (results unchanged).
* Wrong ablation maximum (text cited 40.7, the largest of the listed ablations is 45.5): now the range from the macros.
* E5: B5's reviewer rejected 69.55 held observations per run (printed 69.5) and 22.5 were still held at the end ("rejected the rest" was
  wrong); E8: B5 lost the same 12 observations as PBTI and also held both feeds, so the "cuts both ways" sentence was
  replaced; "no release earlier than R" is now stated as holding by construction.
* Table S5: merged manifests are listed per source run, the final source digest is marked, the regression row cites the
  V3 check; Table S14 includes the mixed workload; Table S19 lists the full PBTI grid behind the worker claims; Table S20
  shows the publisher's send rate (the PBTI publisher, signing in real time on the same host, sent 1,228 and 1,351
  msg/s at offered 1,250 and 1,500); text changed accordingly.
* Rule L bounded check re-run on the final source (the first run had used a pre-final verifier.py); tamper audits re-run
  with the final auditor on all seeds (`results/raw/v3_audit_rerun.jsonl`: same detection outcome in every run).
* `docker compose run` checked: with an empty results volume 7 regression tests fail because the volume hides the
  stored results; with the volume seeded as now documented in `deploy/docker-compose.yml`, all tests pass.
* Author integrity: placeholder ORCID icons removed from the PDF; CRediT roles, funding, conflicts and the
  responsibility sentence of the AI statement are now explicit placeholders; CITATION.cff, LICENSE and README name the
  co-author.
* Smaller corrections: E2/E3 B2 wording, B4's E8 difference named, B4's sweep residue attributed to missing taint, the
  equivocation claim in the Conclusions qualified, regression counts split into revision-2 and V3 specifications, replay
  attribution scope (seeds 1-3 at 1x and 10x), OpenAlex statement, repetition counts justified, PDF metadata keeps the
  multiplication sign, issue-matrix statuses made consistent (novelty margin, overheads, compromise limitations and the
  LOST state are PARTIALLY RESOLVED).
* Not changed: rounding of values ending in 5 follows binary floating point (e.g. 270.15 is stored as 270.1499…), so a
  few one-decimal values round down.
