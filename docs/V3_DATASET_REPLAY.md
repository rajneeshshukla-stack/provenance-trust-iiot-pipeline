# V3 public telemetry replay (X5): dataset, licence, adapter and experiment

Code: `src/pbti/dataset.py` (adapter and replay world), `experiments/run_campaign.py replay` (virtual-time campaign),
`experiments/run_mqtt_e2e.py --payload skab` (MQTT/TLS replay). Results: `results/raw/v3_replay_skab.jsonl`,
`results/raw/v3_mqtt_e2e_skab.jsonl`; provenance record `results/raw/v3_replay_skab_dataset.json`.
Dataset survey of the candidates: `research/V3/literature/V3_DATASETS.md`.

## 3. Content and preprocessing

* 35 CSV files (`;`-separated), one experiment each: `anomaly-free/anomaly-free.csv` (9,405 rows, no labels),
  `valve1/0-15.csv`, `valve2/0-3.csv`, `other/1-14.csv` (745-1,327 rows each).
* Columns: `datetime` (second resolution, time the value was written to the test bed's database), eight sensor
  channels, and for the anomaly files `anomaly` and `changepoint` labels.

| SKAB column | Payload field | Unit (SKAB documentation) |
|---|---|---|
| Accelerometer1RMS | `acc1_rms_g` | g (vibration acceleration RMS) |
| Accelerometer2RMS | `acc2_rms_g` | g |
| Current | `current_a` | A (motor current) |
| Pressure | `press_bar` | bar (loop pressure after the pump) |
| Temperature | `temp_c` | °C (motor body) — the field the attack library manipulates |
| Thermocouple | `fluid_temp_c` | °C (fluid in the loop) |
| Voltage | `voltage_v` | V (motor voltage) |
| Volume Flow RateRMS | `flow_l_min` | l/min (circulation flow) |

* Missing values: none (checked over all 35 files). Non-numeric values: none.
* Timing: 94.6 % of consecutive rows are 1 s apart, 5.3 % 2 s, the rest 3-247 s (checked over all files).
* Files used: `valve1/0-15`, `valve2/0-3`, `other/1-4` (24 files; device (g, j) of the standard topology replays file
  number 6(g-1)+j-1 in this order).
* Window: 600 consecutive rows per file starting at row min(400, n-600), so that the window contains the onset of the
  file's labelled anomaly (anomalies start at about row 560-580 in most files).
* Values are rounded to 6 decimals when placed in the payload; no filtering, resampling or normalization.
* Speed-up k in {1, 5, 10}: the gap between two consecutive observations of a device is the gap between the two
  SKAB rows divided by k.

## 4. Labels: dataset anomalies versus injected attacks

SKAB's `anomaly` labels mark **physical process anomalies** of the test bed (valve closures, cavitation, rotor imbalance,
leaks). They are not attacks, are not part of the payload, and are used only to check that admission does not depend
on process anomalies (`label_breakdown`: availability of legitimate observations in labelled-normal and
labelled-anomalous rows). **Attacks and faults are injected separately** and labelled by the simulator's ground truth,
exactly as in the synthetic scenarios.

## 5. Injected stressors (scheduled in dataset rows r, simulated time r x 1 s / k)

| Stressor | Setting |
|---|---|
| Loss / duplicates / reordering | 2 % / 2 % / 5 % per message |
| Gateway outage | gateway 1 disconnected for rows 100-160 |
| Equivocation (stolen device and relay keys) | one signing device per cell, 5 % of its messages, rows 30-570 (cells 1-2 back-running, 3-4 front-running) |
| Compromise | two cell-4 devices and gateway 4 compromised at row 200 (impersonation, legacy forgery), revoked at row 260 with t_comp = row 200, re-keyed 5 s later (simulated seconds, not rows: at speed-up s, about 5·s rows of each of the six cell-4 devices arrive under the revoked gateway key and are rejected), attempts with the revoked keys continue |
| Relay forgery | gateway 2 (relay key only) forges 72 observations for its own devices; forgeries for its signing devices fail the origin signature, those for its gateway-attested legacy device are admitted, and gateway 2 is never revoked (residue attribution: `results/summary/v3_replay_residue.json`) |

Each speed and pipeline (PBTI, B4, B5) runs seeds 1-20 with stressors and seeds 1-3 without (controls).

## 6. What the replay does and does not show

It exercises the unchanged ingestion pipeline with real multichannel sensor values and the test bed's own timing,
including irregular gaps, at native rate and accelerated. It does **not** contain attacks or failures observed in an
industrial plant, the test bed is not a production plant, and the presence of real sensor measurements does not
validate the provenance-security mechanism.
